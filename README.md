## Overview

This repository contains the complete data and software artifacts accompanying the study **"Charting the Global Landscape of Metal-Ion Battery Research from 128,675 Publications Using AI-Driven Literature Mining"**. It provides:

1. **Processed, text-free CSV datasets** (`Data/`) linking every publication (`DOI`) and abstract sentence (`doi_phrase`) to the machine-learning classifications, topic assignments, composite Relevance Index scores, journal-normalized impact quadrants (`JNIF`), working-ion chemistry tags (`Li-ion`, `Na-ion`, `K-ion`, `Zn-ion`, `Other`), and sentence-level categories of scientific challenges, research directions, and controversies.
2. **End-to-end data enrichment pipeline code** (`Pipeline/`) covering metadata parsing and institution/country sanitization, instruction-tuned embedding generation (`KaLM-embedding-multilingual-mini-instruct-v2.5`), hierarchical density clustering (`EVoC` + `BERTopic`), LLM-based study-type and working-ion extraction (`Gemma-3-4B-IT`), spaCy sentence segmentation, and sentence-level intent extraction and clustering (`all-mpnet-base-v2` + `MiniBatchKMeans`).
3. **Validation and audit scripts** (`Validation/`) used to verify corpus completeness, PRISMA selection funnel counts, topic coherence and diversity ($C_v$, NPMI, $U_{\text{Mass}}$), hierarchical clustering quality indices (Silhouette, Davies–Bouldin, Standard CVI), Relevance Index weight sensitivity, and human expert validation benchmarks.
4. **Analysis and visualization scripts** (`Analysis/`) that reproduce all figures and tables in the main manuscript and Supporting Information.

## Licensing and Proprietary Data Notice

In strict compliance with Clarivate Analytics' licensing terms for the **Web of Science (WoS) Core Collection**, this repository **does not redistribute raw proprietary WoS text or metadata** (such as article titles, abstract text, raw sentence text, raw author address strings, or cited reference lists).

All CSV files in `Data/` contain **only persistent document/sentence identifiers (`DOI`, `Accession Number`, `doi_phrase`) and the derived variables generated by our computational pipeline**. Researchers with institutional access to the Web of Science Core Collection can retrieve the underlying bibliometric records using the search query and DOI lists provided below and in [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) to re-hydrate the text fields for full pipeline re-execution. All downstream statistical analyses, tables, and figures that depend on our derived classifications can be reproduced directly from the CSV files deposited in `Data/`.

## Detailed Contents of `Data/`

All data files are stored in standard UTF-8 CSV format (`.csv`) and contain no raw WoS titles, abstracts, or sentence strings.

### 1. Corpus-Level Datasets

| File | Rows | Columns | Description |
| :--- | ---: | :--- | :--- |
| `initial_corpus_IDs.csv` | 129,789 | `primary_key`, `DOI`, `Accession Number` | Identifiers of all records retrieved from the Web of Science Core Collection on 25 September 2025 before filtering out records without a DOI. |
| `final_corpus_IDs.csv` | 128,675 | `DOI` | List of unique DOIs comprising the final analyzed corpus (after removing 1,114 records lacking a DOI). |
| `final_corpus_data.csv` | 128,675 | 35 columns (`DOI` + 34 processed fields) | Main enriched document-level dataset containing sanitized author/institution/country lists, macro-regions, normalized author keywords, topic assignment (`topic_cluster_1`), Relevance Index scores and ranks (with and without reviews), study type (`research_type`), citation rate (`citations_per_year`), matched Journal Impact Factor (`journal_if`), impact quadrant (`category_group`), `JNIF`, and working-ion chemistry flags (`studied_metal_metal_label`, `is_li_ion`, `is_na_ion`, `is_k_ion`, `is_zn_ion`, `is_other_metal`, `is_irrelevant`). |
| `evoc_topic_layers_by_doi.csv` | 128,675 | `DOI`, `topic_0`, `topic_1`, `topic_2` | Integer cluster assignments across the three retained EVoC hierarchy layers: Layer 0 ($K=67$ fine-grained sub-topics), Layer 1 ($K=23$ primary topics analyzed in the paper), and Layer 2 ($K=7$ macro-domains). |
| `topic_relevance_index.csv` | 23 | 13 columns | Complete topic-level Relevance Index table (with and without review articles), including `n_documents`, `mean_citations_per_year`, `mean_z_score`, `prop_top_10_percent`, `composite_index`, and ordinal rankings (`rank_index`, `rank_index_wo_review`). |

#### Column Dictionary for `final_corpus_data.csv`

- `DOI`: Persistent Digital Object Identifier linking to the original publication.
- `authors_list` / `authors_full_name_list`: Parsed Python-list strings of abbreviated and full author names.
- `first_author` / `last_author` / `first_author_full_name` / `last_author_full_name`: Extracted first and last (senior) author names.
- `authors_institution` / `first_institution` / `last_institution`: Deduplicated and normalized institutional affiliations (sanitized via `2026_03_03_data_sanitization.ipynb`).
- `authors_country` / `first_country` / `last_country`: Standardized country names for all authors, first author, and last author.
- `first_country_region` / `last_country_region`: Macro-regional mapping (`Asia`, `Europe`, `North America`, `South America`, `Oceania`, `Africa`, `Middle East`).
- `author_keywords_normalized_list`: Author keywords normalized via TF-IDF character $n$-gram cosine similarity ($\ge 0.85$) and a curated battery synonym dictionary (`2025_11_11_normalize_keywords_in_df_data.py`).
- `topic_cluster_1`: Assigned topic name among the 23 primary research topics (EVoC Layer 1).
- `topic_rank_index` / `topic_rank_index_position`: Topic Relevance Index score and rank computed over all 128,675 documents (including reviews).
- `topic_rank_index_wo_review` / `topic_rank_index_wo_review_position`: Topic Relevance Index score and rank computed over the 119,372 non-review research articles.
- `research_type`: Methodological classification (`Experimental studies`, `Computational and simulation studies`, `Review`, or unclassified).
- `citations_per_year`: Annualized citation rate ($\text{CPY}$).
- `journal_if`: Matched Journal Impact Factor (JIF) from Clarivate Journal Citation Reports.
- `category_group`: Impact quadrant classification relative to corpus median JIF ($6.50$) and median CPY ($3.75$): `Star (High IF, High Cit)`, `Hidden Gem (Low IF, High Cit)`, `Coattail (High IF, Low Cit)`, or `Long Tail (Low IF, Low Cit)`.
- `JNIF` / `score_log` / `score_sqrt`: Journal-Normalized Impact Factor ($\text{CPY} / \text{JIF} \times 10$) and log/square-root impact composite scores.
- `studied_metal_metal_label`: Raw comma-separated working-ion tag extracted by the LLM (`Li-ion`, `Na-ion`, `K-ion`, `Zn-ion`, `Other`, or `IRRELEVANT`).
- `is_li_ion`, `is_na_ion`, `is_k_ion`, `is_zn_ion`, `is_other_metal`, `is_irrelevant`: Boolean indicators for each battery working ion.
